The satellite only listens ~50 s of every ~95 s (CW beacon phase), so tests wait for it and retry.

Image via SDR + Direwolf

Proof without the ground station: the Nucleo sends the image selected above, the RTL-SDR + Direwolf (a stock decoder, none of our code) receives it, and the bench checks every frame Direwolf delivers: AX.25 addresses, control/PID, the camera fragment of the Packet Format sheet (type 0x08, CRC-16/X.25) and that the picture rebuilt from those fragments is byte-identical to the image sent. The frequency is where your dongle sees the 435.000 MHz signal (its clock error shifts it; 434.9936 for the dongle used so far).

CW HELLO test (spectrum analyzer)

The satellite keys HELLO in Morse on its downlink frequency, 435.000 MHz, over and over: 1 s steady carrier, HELLO (80 ms dit, 240 ms dah), 1.5 s quiet, about 9 s per round. On a TinySA set centre 435 MHz with a narrow span (or zero span) to see the keying; the ground station also decodes it. Stop ends it early; it ends by itself after the time shown. A CW beacon that is already running finishes first (up to ~37 s).

Raw rate test

The satellite (CPU2) sends N packets straight from the radio, with the chosen pause between them (0 = back to back): no flash, no ring buffer, no CW beacon, no per-packet PA sequencing. The GS goes silent and only counts. air rate = what the modem really sustains (200 bytes per packet, from the satellite's own start-to-end time); payload rate = only the 128 file bytes of each packet; lost = packets the GS did not receive. A beacon due during the test is late by up to the length of one run.

2 · Link test

3 · Image downlink test

No file selected. Nothing is built in: the bench sends exactly the file you pick, byte for byte (unless you tick "shrink").

① the PC sends the file chunk by chunk to CPU1 (NuttX), which stores it as a file on LittleFS in CPU1's internal flash (LED blue) → ② the PC reads every chunk back from that file and compares (LED green) → ③ CPU1 reads each chunk from the file into the shared ring buffer (green), CPU2 takes it from the ring and transmits it over RF (yellow) and CPU1 answers A5 5A 06 <seq> <status> 0D 0A; the bench checks the GS printed it (re-sending if not).
